# Start Together

Find a verified business partner in your own city. Static site, free to host on GitHub Pages.

## Launch in 10 minutes (free)
1. Create a GitHub account and click **New repository**. Name it `start-together`, set it to **Public**.
2. Click **uploading an existing file** and upload `index.html`, `.nojekyll` and `README.md`. Click **Commit changes**.
3. Go to **Settings > Pages**. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
4. After 1-2 minutes your site is live at `https://YOUR-USERNAME.github.io/start-together/`.

## Collect real sign-ups (free)
1. Sign up at formspree.io and create a form. Copy its URL.
2. Open `index.html` on GitHub, click the pencil icon, find `var FORM_URL=""` and paste your URL between the quotes.
3. Commit. Sign-ups now arrive in your Formspree inbox.

## Custom domain (optional, about Rs 700-1,000 a year)
Buy a domain, then in **Settings > Pages > Custom domain** enter it and follow GitHub's DNS steps.
